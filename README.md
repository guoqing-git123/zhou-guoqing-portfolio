# 周国庆 · 个人网站

双击 `index.html` 即可浏览，无需安装依赖。网站为纯 HTML / CSS / JavaScript，可将此目录完整部署到任意静态网站托管服务。

参考站：https://anne-huang-portfolio.lovable.app/zh

沿用固定导航、居中首屏、纵向经历、三列项目、六宫格个人展示和联系方式的单页结构。配色调整为米色、暖棕与灰绿，背景使用 CSS 细线和几何轮廓。包含锚点导航、栏目高亮、详情弹窗、Esc 关闭、中英文切换、移动端菜单、简历预览与下载、邮箱复制。

内容来自提供的简历，未添加虚构项目或业绩。项目封面为 SVG 概念示意，已明确标注，并非原始作品。100+ 展示物料为优必选实习期间总量。硕士 2029 年 6 月为预计毕业时间。微信在原简历中为掩码，因此网页未设置微信联系按钮。

修改文字与项目内容：`app.js`；修改配色和布局：`style.css`；原始简历：`assets/resume.pdf`。本站尚未发布至公网。

已接入用户提供的 GlowCursor 发光鼠标拖尾，保留原始 GLSL 着色器并适配为原生 WebGL，无外部运行依赖。香槟金与暖棕渐变，鼠标停止后淡出；减少动态效果模式及触屏设备禁用，不拦截点击。参数位于 glow-cursor.js。
